USB switching

USB host switch

Use an isolated relay or optocoupler in parallel with the included desktop-controller button. Never connect the switch control cable directly to a Raspberry Pi GPIO. Without sentinel observation, the startup host must match the illuminated host and manual button presses cannot be detected.

Choose one USB device that is always connected through the switch. Both workstation agents will watch for this VID/PID and optional serial number; the Pi commits a switch only after the target computer reports the sentinel present.
